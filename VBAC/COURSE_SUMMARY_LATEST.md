## 1. ภาพรวมหลักสูตร

- ระยะเวลา 16 สัปดาห์ สัปดาห์ละ 2 ชั่วโมง รวม 32 ชั่วโมงในแผนหลักสูตร

- ใช้กิจการจำลองของแต่ละกลุ่มเป็นบริบทในการฝึก มีทั้งงานรายบุคคลและงานกลุ่ม
- ทุกสาขาฝึกทักษะแกนเดียวกัน แล้วนำความรู้ในสาขาของตนมาตรวจสอบและต่อยอดผลงาน
- เรียนเสริมกับผู้ให้บริการภายนอกนอกเวลา 32 ชั่วโมง และรวบรวมหลักฐานที่ได้รับจริงลงใน Portfolio

### แนวทางการเรียนรู้

เริ่มจากเข้าใจ AI และส่วนประกอบของระบบ ฝึกสั่งงานและเตรียมข้อมูล ทดลองโมเดลภาพ อ่านและจัดการเอกสาร ทำรายงานและเว็บ เชื่อมงานด้วย Workflow เรียนรู้ AI บนเครื่องและ Agent ก่อนสร้างภาพและวิดีโอโฆษณา แล้วนำเสนอผลงานและส่งพอร์ต

### ผลลัพธ์ที่นำไปใช้ต่อได้

- **อ่านเอกสารและหาข้อมูลเจอ** — ใช้ Typhoon OCR อ่านภาพ จัดหมวดใน Paperless-ngx และให้ AI ช่วยสรุปพร้อมย้อนดูต้นฉบับ; ผลงาน: คลังเอกสารและตัวอย่างคำตอบที่มีที่มา
- **ตรวจยอด แล้วเล่าให้คนเข้าใจ** — ใช้ตารางตรวจตัวเลข ให้ AI ช่วยสรุป และทำสไลด์เสนอสิ่งที่ควรทำจากข้อมูล; ผลงาน: ตาราง กราฟ และสไลด์ข้อเสนอ
- **ทำภาพและคลิปประชาสัมพันธ์** — สร้างภาพด้วย ChatGPT หรือ Nano Banana แก้ใน Canva และใช้ WaveSpeedAI ทำวิดีโอจากภาพ; ผลงาน: ภาพโฆษณาและคลิปสั้นที่ตรวจข้อมูลแล้ว
- **เปลี่ยนความต้องการเป็นเว็บต้นแบบ** — บอกโจทย์ให้ Claude ช่วยเขียนหรือแก้เว็บจากแบบตั้งต้น แล้วทดสอบข้อมูล ลิงก์ และการใช้บนมือถือ; ผลงาน: เว็บหน้าเดียวของร้านที่เปิดใช้งานได้
- **เชื่อมขั้นตอนและลดการคัดลอก** — ใช้ n8n และ Composio เชื่อมเครื่องมือ สร้าง Workflow ช่วยงาน และติด Chatbot บนเว็บให้ AI เลือกทำงานในขอบเขต; ผลงาน: Workflow และ Chatbot บนเว็บ พร้อมผลทดสอบ
- **เลือกใช้และกำกับผู้ช่วยเป็น** — ปรับ Prompt ตรวจความถูกต้อง ทดลอง AI บนเครื่อง สร้าง Agent ประจำหน้าที่ และประสานงานข้ามทีมโดยมีจุดให้คนตัดสินใจ; ผลงาน: Agent ที่มีหน้าที่ เครื่องมือ ความจำ และชุดส่งต่อโครงงาน

### หมวด 1: พื้นฐาน AI และการสั่งงาน

หลักการ AI การเรียนรู้ของเครื่อง การเขียน Prompt และการตรวจสอบผลลัพธ์

**ผลลัพธ์:** กำหนดคำสั่งและประเมินผลลัพธ์ AI ตามเกณฑ์ที่กำหนดได้

### หมวด 2: AI OCR, AI Vision และ Document Management System

การอ่านข้อความและวิเคราะห์ภาพด้วย AI ร่วมกับการจัดเก็บ จัดหมวดหมู่ และค้นคืนเอกสารในระบบจัดการเอกสาร

**ผลลัพธ์:** เลือกใช้ AI OCR และ AI Vision ให้เหมาะกับข้อมูล พร้อมจัดการและค้นคืนเอกสารด้วย Document Management System ได้

### หมวด 3: ข้อมูล รายงาน และงานสำนักงาน

การตรวจสอบข้อมูล การคำนวณ การสร้างกราฟ และการจัดทำรายงานด้วย AI

**ผลลัพธ์:** จัดทำรายงานและสไลด์จากข้อมูลที่ตรวจสอบแล้วได้

### หมวด 4: การพัฒนาโปรแกรมด้วย AI Vibe Code

การพัฒนาโปรแกรมด้วยภาษาธรรมชาติร่วมกับ AI ตั้งแต่กำหนดความต้องการ สร้างต้นแบบ ทดสอบ และปรับปรุงการทำงาน

**ผลลัพธ์:** ใช้ AI ช่วยพัฒนาโปรแกรมต้นแบบจากความต้องการ พร้อมทดสอบและปรับปรุงให้ทำงานตามที่กำหนดได้

### หมวด 5: Chatbot & Workflow Automation

การออกแบบ Chatbot และ Workflow Automation สำหรับเว็บ LINE OA และ Facebook Page

**ผลลัพธ์:** สร้างระบบตอบคำถามและเชื่อมงานอัตโนมัติผ่านช่องทางสื่อสารที่กำหนดได้

### หมวด 6: Local AI และ Private Chat

ความแตกต่างของ Closed-weight และ Open-weight การใช้งานโมเดลในเครื่องและออฟไลน์ และเครื่องมือสำหรับ Private Chat

**ผลลัพธ์:** เลือกใช้โมเดลและเครื่องมือ Private Chat ตามข้อจำกัดของเครื่องและเส้นทางข้อมูลได้

### หมวด 7: AI Agent: Harness, Tool Calling และ Memory

หลักการและการใช้งาน AI Agent ผ่าน Hermes การเรียกใช้เครื่องมือ การจัดการความจำ และการส่งต่อโครงงานระหว่าง Agent

**ผลลัพธ์:** สร้าง Agent ที่มีหน้าที่ เครื่องมือ และความจำ พร้อมส่งต่อโครงงานให้ Agent ตัวอื่นทำงานต่อได้

### หมวด 8: โฆษณาและสื่อประชาสัมพันธ์

การสร้างภาพและวิดีโอโฆษณาด้วย AI เป็นกิจกรรมแยกที่ฝึกได้จากข้อมูลสินค้าตั้งต้น

**ผลลัพธ์:** ผลิตสื่อภาพและวิดีโอให้เหมาะกับกลุ่มเป้าหมายได้

### หมวด 9: บูรณาการโครงงาน AI Day และ Portfolio

การประสานงานข้ามทีม การนำเสนอโครงงานต่อกรรมการ และการจัดทำ Portfolio รายบุคคล

### สัปดาห์ 2: รู้จัก ML และ LLM พร้อมสร้างระบบคิดเงินจากโมเดลภาพ

**หมวด:** พื้นฐาน AI และการสั่งงาน

**เวลา:** ทฤษฎี 24 นาที / ปฏิบัติ 96 นาที

**ผลลัพธ์ที่คาดหวัง**

- อธิบายแนวคิด ML, Model และ LLM ได้ และประยุกต์โมเดลจำแนกภาพที่สร้างเองร่วมกับโปรแกรมคิดเงินที่ให้ AI ช่วยเขียนจาก Prompt ตั้งต้นได้

**เนื้อหาที่เรียน / ประเด็นกิจกรรม**

- รู้จัก Machine Learning (ML) และ Model: การเรียนรู้จากตัวอย่างและการนำโมเดลไปใช้งาน
- แยกข้อมูลฝึกกับข้อมูลทดสอบ และเข้าใจข้อจำกัดของโมเดลจำแนกภาพ
- รู้จัก Large Language Model (LLM) และบทบาทในการสร้างข้อความหรือเขียนโปรแกรมตาม Prompt
- เข้าใจการทำงานร่วมกันของโมเดลภาพที่จำแนกสินค้า กับโปรแกรมที่ใช้รหัสสินค้า ราคา และจำนวนคำนวณยอดรวม
- ทบทวนและทำแบบทดสอบ Microsoft Learn: Fundamental AI Concepts จากเนื้อหาที่เรียนเสริมนอกคาบตั้งแต่สัปดาห์ 1 หากไม่เสร็จให้ดำเนินการนอกคาบและส่งหลักฐานเมื่อผ่าน

**หัวข้อสำคัญ**

- Machine Learning และ Model
- LLM และการเขียนโปรแกรมด้วย Prompt
- ระบบคิดเงินจากโมเดลภาพ

**กิจกรรมที่ผู้เรียนลงมือทำ**

- สร้างโมเดลจำแนกภาพสินค้า 2 ประเภทด้วย Teachable Machine ใช้ชุดภาพตั้งต้นร่วมกับภาพที่เก็บเพิ่ม ฝึก ทดสอบด้วยภาพใหม่ และส่งออกโมเดล
- ใช้ Prompt และโปรแกรมตั้งต้นที่ผู้สอนทดสอบไว้ ให้ AI ช่วยเชื่อมโมเดลภาพกับสินค้าจำลอง 2 รายการและราคา โดยมีปุ่มยืนยันสินค้าก่อนเพิ่มรายการ
- ทดสอบเลือกสินค้าจากผลจำแนกภาพ ยืนยันสินค้าและจำนวนก่อนเพิ่มรายการ ตรวจยอดรวมกับการคำนวณเอง และแก้ข้อผิดพลาด

### สัปดาห์ 3: เข้าใจองค์ประกอบ AI เพื่อประเมินความสามารถและข้อจำกัด

**หมวด:** พื้นฐาน AI และการสั่งงาน

**เวลา:** ทฤษฎี 60 นาที / ปฏิบัติ 60 นาที

**ผลลัพธ์ที่คาดหวัง**

- เข้าใจองค์ประกอบของระบบ AI รวมถึง Context และ Memory และใช้แนวคิดพื้นฐานวิเคราะห์ความสามารถ ข้อจำกัด และสิ่งที่ต้องตรวจสอบของเครื่องมือที่ยังไม่เคยใช้งานได้

**เนื้อหาที่เรียน / ประเด็นกิจกรรม**

- ระบบ AI ประกอบด้วยหลายส่วน: Model, Prompt, Context, Memory, เครื่องมือ และระบบควบคุมการทำงาน ผลลัพธ์ไม่ได้ขึ้นอยู่กับโมเดลเพียงอย่างเดียว
- Prompt Engineering และ Context Engineering: คำสั่ง ข้อมูลอ้างอิง และข้อมูลที่ระบบเข้าถึง ส่งผลต่อคำตอบอย่างไร
- Memory: การเก็บและเรียกใช้ข้อมูลจากการทำงานก่อนหน้า แยกประวัติในบทสนทนากับความจำที่ระบบจัดเก็บข้ามครั้ง และเข้าใจว่าข้อมูลที่จำไว้ต้องถูกเรียกกลับมาเป็น Context จึงจะใช้ประกอบคำตอบได้ ทั้งนี้ขึ้นอยู่กับการตั้งค่าของแต่ละระบบ
- Harness Engineering และ Loop Engineering: ระบบรอบโมเดลเชื่อมเครื่องมือ ควบคุมสิทธิ ตรวจผล และวนปรับการทำงานอย่างไร
- ใช้โครงสร้างของระบบวิเคราะห์ว่า AI น่าจะทำอะไรได้ ต้องพึ่งข้อมูลหรือเครื่องมือใด และมีข้อจำกัดอะไร โดยแยกข้อคาดการณ์ออกจากสิ่งที่ต้องทดลองยืนยัน
- ข้อจำกัดของ Memory: ไม่ใช่ทุกระบบจะจำข้ามการสนทนาได้ ข้อมูลอาจไม่ครบหรือล้าสมัย จึงต้องตรวจสอบและเลือกข้อมูลที่เหมาะสมก่อนจัดเก็บ
- รู้จัก Microsoft 365 Copilot ผ่านข้อมูลตัวอย่าง แล้ววิเคราะห์ว่าเชื่อมกับข้อมูลและเครื่องมือใดได้บ้าง พร้อมเปรียบเทียบกับ ChatGPT และ Claude

**หัวข้อสำคัญ**

- องค์ประกอบของระบบ AI และ Memory
- Prompt, Context, Harness และ Loop
- วิเคราะห์เครื่องมือจากแนวคิดพื้นฐาน

**กิจกรรมที่ผู้เรียนลงมือทำ**

- แยกองค์ประกอบของตัวอย่างระบบคิดเงินจากคาบ 2 ว่าส่วนใดคือโมเดลภาพ LLM คำสั่ง ข้อมูล และโปรแกรมคำนวณ พร้อมอธิบายหน้าที่ของแต่ละส่วน และระบุว่าข้อมูลใดควรเก็บเป็น Memory เพื่อใช้ในครั้งถัดไป
- ลองออกแบบ Loop สำหรับทำงานอย่างง่าย
- วิเคราะห์ Microsoft 365 Copilot จากข้อมูลที่ผู้สอนเตรียม เปรียบเทียบกับ ChatGPT และ Claude โดยระบุความสามารถ ข้อจำกัด และสิ่งที่ต้องทดลองยืนยัน

**การแบ่งเวลาในคาบ**

- 20 นาที วิเคราะห์องค์ประกอบและ Memory รายบุคคล

### สัปดาห์ 4: AI OCR และ AI Vision: อ่านและวิเคราะห์เอกสาร

## 4. เครื่องมือและบทบาทในหลักสูตร

รายการนี้สรุปบทบาทตามที่หลักสูตรระบุ ไม่ใช่รายการความสามารถทั้งหมดของแต่ละผลิตภัณฑ์

### Gemini

ใช้ช่วยสรุปข้อมูลและเตรียมรายงานในคาบข้อมูล ผู้เรียนตรวจตัวเลขและแหล่งข้อมูลเอง

### Teachable Machine

เครื่องมือของ Google สำหรับทดลองฝึกโมเดลจำแนกภาพ โดยไม่เขียนโค้ด

### Paperless-ngx

ระบบรับเอกสาร ทำ OCR จัดหมวด ติดป้าย และค้นข้อความ ครูติดตั้งและเตรียมบัญชีไว้ให้

### Google Docs

ใช้เขียนเอกสารและคู่มือ เปลี่ยนเป็นโปรแกรมเอกสารที่ห้องเรียนมีได้

### Google Sheets

ใช้ตรวจยอดและทำตาราง เปลี่ยนเป็น Excel ที่ห้องเรียนมีได้

### Google Slides

ทำสไลด์สรุปข้อเสนอ เปลี่ยนเป็น PowerPoint ได้

### Canva

นำภาพที่สร้างด้วย ChatGPT มาจัดหน้า เพิ่มและแก้ข้อความ โลโก้ ราคา จากนั้นประกอบคลิปที่สร้างด้วย WaveSpeedAI พร้อมเสียงและคำบรรยาย

### ElevenLabs

ตัวอย่างบริการเสียงสังเคราะห์ ใช้ตามสิทธิและเงื่อนไขอายุ หากไม่พร้อมให้อัดเสียงเอง

### HTML

รูปแบบไฟล์เว็บที่ใช้ทดลอง โดยครูให้แบบตั้งต้นและให้ AI ช่วยแก้

### n8n

เชื่อมแบบฟอร์ม ตาราง และข้อมูลเอกสาร ผ่านขั้นตอนที่ครูเตรียมไว้

### Ollama

รันโมเดลบนเครื่องที่ครูเตรียมและทดสอบแล้ว

### Open WebUI

หน้าจอสำหรับคุยกับโมเดลในระบบที่เตรียมให้

### Hermes Agent

AI Agent สำหรับฝึกติดตั้ง ตั้งค่า เชื่อมโมเดล และใช้เครื่องมือในสภาพแวดล้อมทดลองที่ผู้สอนเตรียม

### ChatGPT

ช่วยร่างข้อความและสร้างภาพโฆษณาจากโจทย์ แล้วดาวน์โหลดภาพไปจัดหน้าและแก้ข้อความใน Canva ใช้ตามสิทธิและโควตาบัญชี

### Claude

ช่วยอ่านเอกสารที่อนุญาต สรุปเงื่อนไข และช่วยเขียนหรือแก้ HTML จากแบบตั้งต้น ผู้เรียนตรวจงานก่อนใช้

### WaveSpeedAI

ใช้ wavespeed.ai สร้างวิดีโอจากภาพและคำสั่ง เลือกโมเดล ความยาว และเครดิตที่ครูทดลองไว้ แล้วนำคลิปไปตัดต่อใน Canva

### Nano Banana (Gemini)

เครื่องมือสร้างและแก้ภาพใน Gemini ใช้ทดลองโจทย์เดียวกับ ChatGPT แล้วเลือกภาพไปจัดต่อใน Canva ตามรุ่น สิทธิ อายุ และโควตาบัญชีที่พร้อม

### Typhoon OCR

อ่านภาพหรือ PDF เป็นข้อความ ใช้ทดลองเอกสารภาษาไทยและตรวจข้อความกับต้นฉบับ ก่อนเก็บผลที่ตรวจแล้วคู่กับเอกสารใน Paperless-ngx ผ่านระบบหรือ Playground ที่ครูเตรียม

### Composio

เชื่อมเครื่องมือและบัญชีที่อนุญาตให้ Workflow หรือ Agent เรียกใช้ เช่น ตารางสินค้าและรายการคำขอ ครูเตรียมระบบฝั่งเซิร์ฟเวอร์ บัญชีทดสอบ และสิทธิไว้ก่อนเรียน ไม่ใช่ตัวสร้างหน้า Chatbot โดยลำพัง

### LINE OA

ช่องทาง Chatbot ผ่าน LINE Messaging API ใช้บัญชีทดสอบและ Webhook ที่ผู้สอนเตรียมไว้

### Facebook Page

ช่องทาง Chatbot ผ่าน Messenger ของเพจ ใช้เพจ บัญชีผู้ทดสอบ และสิทธิที่ผู้สอนเตรียมไว้

### Gmail

ส่งอีเมลจาก Workflow ผ่านบัญชีทดสอบที่ผู้สอนเตรียม

### Google Drive

บันทึกไฟล์หรือผลการทำงานจาก Workflow ลงโฟลเดอร์ที่กำหนด

### OpenRouter

เชื่อมบริการโมเดล AI ให้ Chatbot ใน n8n โดยใช้ API key และโมเดลที่ผู้สอนเตรียม พร้อมตรวจค่าใช้จ่ายและเงื่อนไขการส่งข้อมูล

### Codex

ตัวอย่าง Agent สำหรับช่วยพัฒนาโปรแกรมและทำงานกับไฟล์โครงงาน ตามสิทธิของบัญชีที่เตรียม

### Claude Code

ตัวอย่าง Agent สำหรับช่วยพัฒนาโปรแกรมและใช้เครื่องมือกับโครงงาน ตามสิทธิของบัญชีที่เตรียม

## 7. กรอบ Level ผู้ใช้ AI

PROPOSED FRAMEWORK · AI USER CAPABILITY

เป็นกรอบเสนอเพื่อช่วยมองพัฒนาการของผู้ใช้ AI ไม่ใช่เกณฑ์สอบหรือการรับรองระดับเมื่อเรียนจบ และไม่มีป้ายระดับกำกับหมวดใน Roadmap แล้ว

### Level 1: AI Explorer

**ใช้ AI ถามตอบและช่วยงานทั่วไป**

พิมพ์ถามสิ่งที่อยากรู้ ให้ช่วยแปล สรุป เขียนข้อความ หรือสร้างภาพ แล้วอ่านตรวจและนำคำตอบไปใช้

เช่น ให้ AI ช่วยร่างโพสต์ขายสินค้า

### Level 2: AI Context Designer

**ผู้จัดเตรียมข้อมูลให้ AI**

เข้าใจ Context engineering คือการเตรียมข้อมูลให้ AI รู้เรื่องงานก่อนลงมือทำ บอกว่างานนี้ทำให้ใคร ต้องการอะไร มีเงื่อนไขอะไร พร้อมให้เอกสารหรือตัวอย่างที่จำเป็น และเลือกข้อมูลให้เหมาะกับแต่ละงาน

เช่น ให้ข้อมูลร้าน กลุ่มลูกค้า ราคา และตัวอย่างโพสต์ ก่อนให้ AI เขียนโพสต์ขายสินค้า

### Level 3: AI Operator

**เชื่อม AI กับแอปที่ใช้ทำงาน**

เชื่อมต่อให้ AI ช่วยทำงานในแอปอื่นได้ เช่น หาไฟล์ใน Google Drive อ่านอีเมล หรือเพิ่มข้อมูลใน Google Sheets โดยเราสั่งและตรวจงาน

เช่น สั่งให้ AI หาใบเสนอราคาใน Drive แล้วสรุปให้

### Level 4: AI Automator

**ตั้งให้งานทำต่อกันได้เอง**

จัดขั้นตอนให้งานที่ทำบ่อยเดินต่อได้อัตโนมัติ ไม่ต้องสั่งใหม่ทีละขั้น และรู้ว่าต้องแก้ตรงไหนถ้าระบบทำงานไม่สำเร็จ

เช่น เมื่อลูกค้ากรอกฟอร์ม ให้ AI สรุป บันทึกข้อมูล และส่งแจ้งเตือน

### Level 5: AI Agent Builder

**สร้างผู้ช่วย AI ของตัวเอง**

กำหนดหน้าที่และเครื่องมือให้ AI รับงานไปคิดและลงมือทำ รู้จักใช้ Memory ให้จำข้อมูลที่ต้องใช้ต่อ และเขียนไฟล์ .md เป็นคู่มือบอกว่าควรทำงานอย่างไร

เช่น สร้างผู้ช่วยที่จำข้อมูลร้าน และเลือกค้นข้อมูลก่อนตอบลูกค้า

### Level 6: AI Orchestrator

**ให้ผู้ช่วย AI หลายตัวทำงานร่วมกัน**

แบ่งหน้าที่ให้ AI แต่ละตัว เช่น ตัวหนึ่งหาข้อมูล ตัวหนึ่งเขียน อีกตัวตรวจ แล้วจัดให้ส่งงานต่อกัน พร้อมดูคุณภาพ ค่าใช้จ่าย และเรื่องที่ต้องให้คนตัดสินใจ

เช่น ให้ทีม AI ช่วยทำบทความ ตั้งแต่หาข้อมูลจนถึงตรวจงาน

ไม่จำเป็นต้องอยู่ระดับเดียวกันทุกงาน เริ่มจากสิ่งที่ทำได้คล่อง แล้วค่อยฝึกสิ่งถัดไป

## 8. การประยุกต์ใช้ในแต่ละสาขา

- **บัญชี / โลจิสติกส์:** ค้นเอกสาร ตรวจตัวเลข และติดตามสถานะ
- **การตลาด / กราฟิก:** ทำภาพ คลิป และข้อความจากข้อมูลที่ตรวจแล้ว
- **ท่องเที่ยว / การจัดการ:** สรุปเงื่อนไข เตรียมข้อมูล และติดตามงาน
- **ไอที / ธุรกิจดิจิทัล:** ทำเว็บต้นแบบและเชื่อมขั้นตอนการทำงาน

## 10. ขอบเขตของสรุปฉบับนี้

- ใช้เนื้อหาใน `VBAC/index.html` เป็นแหล่งข้อมูลหลัก เพื่อให้ตรงกับหน้าเว็บล่าสุด
- รายละเอียดรายคาบ เครื่องมือ ผลงาน และเกณฑ์ตรวจ ถอดจากข้อมูลที่หน้าเว็บใช้แสดงผล
- ไม่รวมไฟล์ภาพใบประกาศหรือข้อมูลภาพแบบ Base64 ลงในเอกสาร
- ไม่กำหนดน้ำหนักคะแนน เกณฑ์ตัดเกรด หรือเงื่อนไขรับรองระดับเพิ่มเติมจากต้นฉบับ
